    Method

    • Forwards implied per expiry from put–call parity near the money, so dividends and carry come from the market, not an assumption.
    • Implied vols from Black-76 on OTM quotes (bid, mid and ask), then a raw-SVI fit per expiry with spread-weighted robust least squares.
    • 25Δ points use undiscounted forward delta. Constant-maturity values interpolate total variance in time.
    • GEX assumes dealers are long calls and short puts, the usual naive convention. Real positioning is unobservable, so read it as a map of where open interest concentrates gamma, not a forecast.
    • Realised vol is annualised over 252 days. The vol cone uses rolling close-to-close windows over the full history.
